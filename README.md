# Eaven Ball — Portfolio

🌐 **Live Site:** [eavens-portfolio.vercel.app](https://eavens-portfolio.vercel.app)

---

## About

I'm Eaven Ball — a developer with experience across game development, software engineering, AI tooling, and web development. This site is where I share my projects, skills, and a bit about who I am. It includes sections for Projects, About, and Contact.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org) (App Router)

- **Styling:** CSS / Tailwind CSS

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/eball0509/EavensPortfolio.git
cd EavensPortfolio
npm install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

---

## Deployment

I deploy this project via [Vercel](https://vercel.com). To deploy your own fork:

1. Push your changes to GitHub.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Vercel will auto-detect Next.js and handle the build configuration.

See the [Next.js deployment docs](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
